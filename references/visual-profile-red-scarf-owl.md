# 红围巾猫头鹰 × 撕纸拼贴视觉 Profile

## 适用范围与调用方式

这套 Profile 用于 AI 产品文章的封面、章节插图、知识图解和配套社交媒体图片。

显式调用方式：

```text
使用红围巾猫头鹰拼贴视觉配置。
```

选中该配置后，本文件是详细视觉规则来源。用户当前明确要求优先；一次性变体只影响当前成品，不自动改写本 Profile 或已经固定的长期角色标准。

## 角色不变量

主角是一只主体细节偏写实、带编辑拼贴质感的猫头鹰，代表作者、产品经理、个人开发者或项目负责人。跨图保持以下识别点一致：

- 白色面部；
- 棕黑色羽毛；
- 黄色眼睛；
- 有真实布料质感的红围巾；
- 橄榄绿色外套。

角色气质以专注、思考、检查、发现问题和推进工作为主，不做儿童吉祥物式卖萌。

### 手臂与手部硬规则

只要画面出现手臂或手，无论是否正在操作电脑、纸张、笔、文件、印章或其他工具，以下规则都适用：

- 手臂必须是与翅膀清楚分离的纯黑火柴人线条；
- 手掌和手指必须是实心黑色、正常粗细、比例自然的简化人手，能够清楚表现拿笔、指向、翻页或敲键盘；
- 翅膀可以存在，但不能承担抓握、指向或操作物件的手部功能；
- 禁止骨架手、骷髅手、白骨手、骨骼结构、过细手掌或手指；
- 禁止把猫头鹰翅膀直接当成人类手臂、手掌或手指。

## 纸张拼贴视觉系统

整体视觉为“编辑杂志拼贴 × 现实工作台 × 手写批注”，不是企业信息图。

- 背景使用暖白至浅米色纸张，只保留轻微、均匀的纸张纤维和少量印刷颗粒；
- 墙面保持干净，禁止重度斑驳、大片污损、发霉感、过度泛黄或满屏噪点；
- 人物、文件、设备与主要物件保留清楚的撕纸白边和轻微纸影，形成真实手工层叠感；
- 撕纸块保持自然轮廓，不能被整理成统一的 UI 卡片；
- 红色粗笔大标题是主要视觉锚点；
- 蓝色手写批注配合箭头、圈画、下划线、星号或问号承担解释；
- 橄榄绿色信息纸片承载辅助信息；
- 正文线稿使用墨黑或深灰，少量警示红或橙只用于风险、失败或关键转折。

## 信息层级与现实物件

- 画面可以信息丰富，但必须有单一主焦点、清楚主次和明确阅读顺序；
- 不能为了“干净”删除已经确认或表达主题所必需的重要信息；
- 角色通常位于中部或一侧的视觉重心，不能缩成角落装饰；
- 每张图只承担一个核心关系或一个主要问题；
- 信息通过纸张、档案、工作台、箭头与批注组织，不采用标准卡片网格。

按文章主题选用现实工作物件，不要求每张图全部出现：

- 旧电脑或普通笔记本电脑；
- 笔记本、项目文件、PRD、测试报告、便签、文件夹或档案盒；
- 录音设备、磁带、录音波形或会议材料；
- 回形针、图钉、胶带、印章、钢笔或尺子；
- 植物、咖啡杯及其他真实桌面物件。

AI 对话窗口、代码片段和版本记录可以作为剪贴材料，但不能把整张图变成产品界面。所有物件都服务于文章内容和信息层级，不堆成无关装饰。

## 禁止方向

禁止出现：

- SaaS 圆角卡片、仪表盘式企业信息图或咨询公司 PPT；
- 扁平矢量人物、统一线性图标；
- 赛博朋克、霓虹发光、科技渐变；
- 玻璃拟态；
- 复杂 3D 商业插图、股票广告或商业宣传片式精修；
- 过度规整的等宽模块网格；
- 重度斑驳、脏乱或 grunge 墙面；
- 为了增加留白而删掉已经确认的重要信息；
- 在用户只要求局部调整时重新设计整套风格。

## 中文文字与逐字 QA

1. 生成前建立文字清单，逐项写明准确文案、层级和位置。
2. 标题、关键结论、标签等重要中文优先留出干净区域，再用可编辑文字层确定性排版，不把关键中文交给图像模型碰运气。
3. 若图像模型直接生成中文，交付前逐字对照文字清单，检查错字、漏字、多字、繁简混用、错误标点、错误断行、遮挡、截断、乱码与伪文字。
4. 发现任一文字错误时，必须局部修复或重做后再交付。OCR 只能辅助，不能替代逐字目视比对。
5. 背景与装饰层不得遗留无意义伪文字。

## 固定生产流程

必须依次经过以下阶段，不得合并两次确认：

1. **样稿**：先生成一张能够完整暴露角色、材质、信息层级和中文问题的代表性样稿。此时角色只是候选，不开始批量生成。
2. **用户反馈修改**：把反馈拆成“变更维度”和“锁定维度”，只修改被点名的部分。
3. **确认角色与风格**：用户明确确认角色与风格可作为本批次生成基线后，才进入批量阶段。这不是长期角色固化。
4. **批量生成**：锁定已经确认的脸部识别点、羽毛、眼睛、围巾、外套、配色和拼贴语言，只让内容、动作、场景、道具与必要构图随文章变化，并逐张执行中文 QA。
5. **整组确认**：检查跨图角色一致性、信息层级、禁止方向和全部中文，让用户确认整组图片。
6. **固定角色**：只有用户明确确认整组图片后，才把最终角色形象固定为后续长期标准。不能把样稿通过、单张满意或用户沉默推定为长期固定。

## 局部修改边界

每次编辑前先明确“只改什么”和“必须保持什么”。未被点名的角色身份、脸部、羽毛、服装、配色、构图、裁切、画幅、背景、物件、文字、信息密度和质感全部保持。

优先基于原图做局部编辑，禁止用整张重生成冒充局部修改。若工具限制会造成明显的连带变化，先说明具体影响并取得用户明确确认后再继续；否则停止，或改用能够保持锁定维度的方案。

当前成品的一次性改动不自动成为下一张图或长期角色的新默认。

## 交付前检查

- 白脸、棕黑羽毛、黄色眼睛、红围巾、橄榄绿外套五个识别点齐全；
- 纯黑火柴人手臂与正常粗细的黑色手掌、手指正确，没有骨架手、白骨手或翅膀当手；
- 暖白浅米纸张背景、轻纹理、撕纸白边与轻纸影正确，墙面没有重度斑驳；
- 红色粗笔大标题、蓝色手写批注与橄榄绿信息纸片使用正确；
- 现实物件与主题有关，信息丰富但主次清楚；
- 禁止视觉方向没有出现；
- 全部重要中文已按文字清单逐字确认；
- 批量图片中的角色与视觉语言一致。
