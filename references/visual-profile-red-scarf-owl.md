# 红围巾猫头鹰拼贴视觉 Profile

## 调用边界

本 Profile 的调用名为“红围巾猫头鹰拼贴”。仅在用户明确指定或确认采用这个方向时加载。它是一套可替换的文章视觉配置，不是所有文章、所有平台或所有配图的默认形象；真实产品截图、数据图、证据图片和用户另行指定的视觉方向优先。

本 Profile 固定角色身份、编辑拼贴语言、色彩和失败边界。每篇文章仍要先从内容中抽取具体关系，再决定场景、道具和构图，不能把同一张模板换标题反复使用。

## 固定角色

- 主角是一只偏写实的拟人猫头鹰。白色面盘清楚，棕黑色斑点羽毛保留自然层次，眼睛为醒目的黄色。
- 固定佩戴有布料质感的红色围巾和橄榄绿色外套。服装可以随动作产生自然褶皱，颜色与身份特征不能在同一系列中漂移。
- 角色承担作者、个人开发者、产品经理或项目负责人的语义，是正在观察、整理、判断和验证的人，不是缩在角落里的可爱吉祥物。
- 表情以专注、思考、检查、犹豫和发现问题为主，避免夸张卖萌、怪物化或无关的戏剧表情。
- 需要拿笔、翻文件、敲键盘、拖动、指向或操作设备时，必须使用独立的纯黑色火柴人风格手臂与手掌。手臂从身体两侧自然连接，手掌轮廓简洁、完整并能承担动作。
- 禁止骨架手、骨头手指、翅膀当手、翅膀与手臂混用、悬空手臂、多手、多臂、重复肢体和畸形手指。

封面确认后，把该版猫头鹰作为本系列的角色标准图。后续图片允许更换动作、视角、场景和手中道具，不允许改变面盘、羽毛、眼睛、围巾、外套、身体比例或手部结构。

## 视觉语言

- 整体是编辑杂志式撕纸拼贴，画面像一张由照片、纸片、实物和手写编辑痕迹共同组成的专题页，不能退化成规整的 SaaS 信息图。
- 背景使用暖白纸张或暖白墙面。保留轻微纸纹、细小印刷颗粒和少量真实使用痕迹，让画面有触感但仍然干净。墙面不能大面积斑驳、发霉、剥落、油污化或做旧到显脏。
- 人物、重点物件和局部场景可以带撕纸白边、剪贴轮廓与轻微纸张阴影。胶带、图钉、回形针和纸片用于建立层次与连接关系，不能随机堆满画面。
- 优先使用有真实尺度和材质的电脑、文件、打印纸、文件夹、录音机、笔记本、笔、档案盒、便签和印章。物件必须服务文章语义，不能用无关装饰替代关键信息。
- 构图允许不对称、叠放和局部越界，但阅读路径必须受控。信息密度可以高，标题、角色、主要关系和结论仍要一眼分层。
- 每张图表达一个核心关系，同时保留理解该关系所需的节点、状态、对象和方向。画面干净不等于信息少；不能删除文章中的关键项目语义来换取空白。

## 色彩与文字

- 背景为暖白。正文与线条使用墨黑或深灰。
- 主标题使用红色粗笔、丝网印刷或剪贴字质感，红色同时与围巾形成系列锚点。
- 批注、箭头、圈画和下划线使用钴蓝色手写语言。它们必须标出真实关系或重点，不能成为无意义涂鸦。
- 橄榄绿色纸片或色块用于承托分组、场景或次级信息，并与角色外套呼应。
- 其他颜色只少量使用。需要表达风险、转折或待处理状态时，可以加入少量警示橙，但不能破坏红、蓝、橄榄绿与暖白的主系统。
- 图片文字以短标题、关键词、状态和必要标签为主。重要中文、数字和长句使用确定性排版，不把最终准确性押给图像模型。
- 先为文字预留安静区域，再安排角色与拼贴物件。文字不能压在高纹理背景、脸部、手部或关系节点上。

## 构图与信息密度检查

出图前先写清：

1. 这张图要解释的唯一核心关系。
2. 读者必须看见的对象、状态和连接。
3. 猫头鹰在关系中正在做什么。
4. 哪些真实物件承载项目语义。
5. 标题、蓝色批注和橄榄绿承托分别落在哪里。

缩略图先检查标题和主视觉，原尺寸再检查信息是否完整。发现画面拥挤时，优先合并重复装饰、拉开层次或调整阅读路径，不能先删掉核心节点。发现画面过空时，补回与文章直接相关的文件、状态、箭头、材料或工作现场，不能填充无关图标。

## 明确避免

- 过脏、过度斑驳、重度复古做旧、污渍墙面和暗褐色废墟感。
- 白底圆角卡片阵列、企业流程图、咨询公司 PPT、仪表盘和等宽等高模块。
- 扁平矢量人物、统一线性图标、图库广告感和把猫头鹰缩成角落装饰。
- 科技渐变、霓虹赛博朋克、发光节点、复杂 3D、玻璃拟态和悬浮 UI。
- 为追求极简而丢失流程节点、状态差异、文件关系、下一步或其他项目语义。
- 让生成模型直接承担长段中文或关键数字的最终排版。
